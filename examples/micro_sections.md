# Шпаргалка по Git

Краткий справочник по командам Git для повседневной работы.

## Настройка

### Глобальная конфигурация

Имя и email для коммитов.

### git config

```bash
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
```

### Алиасы

Полезные сокращения.

### git config alias

```bash
git config --global alias.co checkout
git config --global alias.br branch
git config --global alias.st status
git config --global alias.lg "log --oneline --graph --all"
```

## Создание репозитория

### git init

Инициализация нового репозитория.

### git clone

## Базовые операции

### git add

Добавление файлов в staging area.

### git commit

Фиксация изменений.

### git status

Просмотр текущего состояния.

### git diff

Просмотр изменений.

### git log

История коммитов.

## Ветвление

### git branch

Создание и просмотр веток.

### git checkout

Переключение между ветками.

### git switch

Современная альтернатива checkout для переключения.

### git merge

Слияние веток.

### git rebase

Перебазирование — перенос коммитов на другую базу.

### git cherry-pick

Выборочный перенос коммита.

## Удалённые репозитории

### git remote

Управление удалёнными репозиториями.

### git fetch

Загрузка изменений без слияния.

### git pull

Загрузка + слияние.

### git push

Отправка изменений.

## Отмена изменений

### git restore

Отмена изменений в рабочей директории.

### git reset

### git revert

Создание коммита, отменяющего другой.

### git stash pop

Восстановление сохранённых изменений.

### git stash list

### git stash drop

## Советы

### Атомарные коммиты

Один коммит — одно логическое изменение.

### Осмысленные сообщения

Описывайте «почему», а не «что».

### Частые коммиты

Лучше часто и мелко, чем редко и много.

### Не коммитьте секреты

Пароли, ключи API, токены — в .gitignore или .env.

### Подписывайте коммиты

GPG-подпись для верификации авторства.

### Защищайте main

Merge только через pull request с review.
