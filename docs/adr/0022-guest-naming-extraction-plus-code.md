# ADR-0022: Наминг представленного гостя — экстракция LLM, назначение кодом

## Статус

Принято (2026-07-30), реализовано в `services/asr-adaptor/stages/namer.py`. Проверено на четырёх
типах выпусков (гость с ложным voice-match, выпуск без гостя, обычный гость, гость из реестра).

## Контекст

Наминг просил LLM сопоставить меткам `Speaker_N` имена из интро. Для ведущих это самоназвания
(«меня зовут…» — в чьей реплике звучит, тому и имя), а для гостя — вывод методом исключения:
его представляет ведущий, и чья метка у гостя, формально из текста не следует. Grok этот вывод
делал молча, и на нём держался весь наминг гостей. Deepseek (ADR-0021, смена модели) строго
отказывается спекулировать: на `ep2-20` трижды вернул `null` даже для дословно представленного
Колодезева — и выпуск молча ушёл под ложный voice-match реестра («Натёкин» вместо гостя
Бабушкина), причём без записи конфликта: спорить с реестром стало некому. Два промпт-разрешения
(«атрибутируй отвечающего», «исключение — разрешённый вывод») поведения не изменили — 6 прогонов.

## Решение

Разделение труда, как в глоссарии и финал-раунде: **LLM извлекает, код решает.**

- LLM получает recall-задачу без атрибуции: «перечисли гостей, которых представили ведущие»
  (именительный падеж, полное имя). Вызов **удвоен с объединением** — одиночный оказался лотереей
  (2 из 3), дедуп по фамилии схлопывает «Валера/Валерий Бабушкин» в полную форму.
- Метку назначает код, только когда вывод однозначен: ровно один гость И ровно одна свободная
  метка (не ведущий, подтверждённый интро, и не именованная самоназванием) И имя гостя реально
  звучит в тексте интро (защита от фантазии экстрактора). Дальше работает прежняя лестница
  разрешения конфликтов — на `ep2-20` она честно даёт `used_intro` против неподтверждённого реестра.
- Неоднозначность (двое гостей, две свободные метки) → метка остаётся `Speaker_N`: невыставленное
  имя дешевле свопа людей.

## Последствия

- `ep2-20` подписывается верно 3/3 с записанным конфликтом; выпуски без гостя ложного гостя не
  получают (фраза «Записываюсь от Ивана Комарова» на `ep2-28` гостя не породила — свободных меток нет).
- Третье подтверждение паттерна: у deepseek промпт не меняет поведения там, где нужен вывод или
  запрет; двигают код и структурные задачи. Grok-вольности, на которых незаметно держалась логика,
  при смене модели становятся регрессиями — искать их надо прицельными прогонами известных кейсов.
- Мульти-гость (двое и больше) намеренно не покрыт — остаётся `Speaker_N` до Слоя 2 (LLM-аудитор
  из доки приключения).
