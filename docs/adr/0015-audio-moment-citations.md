# ADR-0015: Цитаты-моменты для timestamped-корпусов (аудио/видео)

## Статус

Принято (2026-07). Реализовано на main (`retrieval.features.timestamp_citations`, off по умолчанию).
Обкатано на публичном деплое RAG по подкасту «Капитанский мостик» (53 выпуска, 70 часов звука).

## Контекст

Для корпусов из аудио-расшифровок смысл цитаты — привести слушателя в **конкретную секунду записи**
(«послушай сам, как это было сказано»), а не сослаться на файл целиком. Данные для этого есть:
транскрипт-чанкер (`mode: transcript`) кладёт в payload каждого чанка `start_sec`/`end_sec`/`speakers`,
а `url` указывает на исходный mp3 — deep-link строится как `{url}#t={start_sec}` (Media Fragments,
браузеры играют с указанной секунды).

Однако цитирование было документо-центричным на трёх уровнях:

1. **Нумерация `[N]`** (`_doc_numbering`) назначалась per-документ: агент цитировал «выпуск №15»,
   а не момент внутри него.
2. **OWUI склеивает citation-события по `source.name`** (= заголовок документа): все моменты одного
   выпуска схлопывались в одну файловую карточку.
3. **`source.url` карточки** нёс базовый URL без `#t=` — а именно его OWUI открывает по клику.
   Deep-link жил только в per-чанк `metadata[].url`, которую UI для клика не использует.
   (Пункт 3 был найден только живым кликом в UI — CLI-проверка смотрела metadata и багу не видела.)

## Решение

Ввести **единицу цитирования** (`_citation_unit(chunk)`): при включённом флаге и наличии `start_sec` —
МОМЕНТ (ключ `{doc_id}#{sec}`, метка `«Выпуск · MM:SS · Спикер»`, url с `#t=`), иначе — документ
(прежнее поведение). От единицы пляшут все три точки: рендер результатов агенту
(`[N] Выпуск · MM:SS · Спикер` + текст реплики), финальная таблица `[N] → метка` перед ответом,
и citation-события (у каждого момента свой `source.name` → OWUI не склеивает; `source.url` = deep-link
первого чанка).

Защита документных корпусов двойная: флаг `timestamp_citations` по умолчанию off, и даже при on
ветвление идёт по наличию `start_sec` в payload, которого у документных чанков нет. Документный путь
проверен байт-в-байт (рендер, нумерация, события).

## Последствия

- Ответ агента превращается в навигатор по записи: каждый тезис — кликабельная секунда с указанием
  спикера. Атрибуция проверяема ухом.
- `get_doc` и Jira-цитаты остаются документо-уровневыми (чтение выпуска целиком — осмысленная
  операция без момента).
- Точность секунды = старт реплики; для суб-чанков длинного монолога — интерполяция
  (см. TODO «тонкий тайминг» в доке приключения). Для deep-link «слушай примерно отсюда» достаточно.
- Урок процесса: проверять надо тот слой, который реально рендерится у пользователя
  (CLI-проверка metadata пропустила баг `source.url`).
