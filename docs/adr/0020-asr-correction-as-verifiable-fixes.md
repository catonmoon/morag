# ADR-0020: Правка расшифровки — проверяемые замены вместо свободного переписывания

## Статус

Принято (2026-07-30), реализовано в `services/asr-adaptor/stages/final_round.py`. Валидировано
серией замеров на четырёх выпусках «Капитанского мостика» (журнал —
`adventures/experiments/asr_final_round_20260730.md`); корпусный перепрогон — в процессе.

## Контекст

Финал-раунд (ADR-0017) отдавал LLM фрагмент расшифровки и принимал обратно **переписанный текст**,
полагаясь на промпт «правь только сущности, остальное дословно». Замеры показали, что промпт эту
границу не держит, а отказы молчаливы и катастрофичны:

- обрезанный ответ модели удалил **365 слов речи** из одной реплики (401→36, обрыв на полуслове);
- верно распознанное имя ведущего вернулось гарблом («Колодезев»→«Колодзев»);
- по корпусу — 2069 замен кириллицы на латиницу («умные очки»→`smart glasses`): модель считала
  перевод канонизацией; явный запрет в промпте дал 65→69 замен, то есть ничего;
- пары сущностей подменялись правдоподобными соседями по контексту («WeChat»→«Alipay»).

Проверки переписанного текста постфактум (объём ответа, смена письма) — гадание: генерация
недетерминирована, и ту же реплику, что модель обрезала в одном прогоне, она корректно правила в
другом.

## Решение

**У модели не берут прозу.** Она возвращает структурированный список замен
`{"fixes":[{"was":..,"now":..}]}`, где `was` — фраза из фрагмента дословно, 1-3 слова. Применяет
замены код (`apply_fixes`), проверяя каждую по отдельности; текст вне замен остаётся байт-в-байт.
Это тот же принцип разделения труда, что и во всей схеме ADR-0017: *LLM = recall (предлагает),
детерминированный код = precision (решает)*.

Барьеры на замену — каждый из наблюдавшегося отказа, не из общих соображений:

1. пустая/тождественная; `was` > 3 слов или `now` неправдоподобно длинное — переписывание, не сущность;
2. `was` нет в тексте **по границам слова** («СМЛ»→ASML внутри «АСМЛ» дало «АASML»);
3. **изъятие** — `now` ⊂ `was` по словам и короче: канонизация всегда что-то приносит
   (19 изъятий на 4 выпуска, 8 меняли смысл: «Roosevelt и Churchill»→«Roosevelt»);
4. **смена числа** — обе стороны с цифрами и цифры разные: число решает акустика, не контекст
   (зеркало правила глоссария; поймано чтением: контекст «нормализовал» H200→H100 под соседей);
5. **перевод** — частотное русское → сплошь строчное частотное английское, без санкции глоссария
   (имя распознаётся по капитализации: «сам Артман»→Sam Altman остаётся);
6. порча **известного термина корпуса** (`ASR_ALWAYS_TERMS`) — проверка по результату применения,
   вхождением подстроки (склонения покрываются даром; стеммер проверен и отвергнут — склонений у
   защищаемых имён в корпусе нет, а стоил зависимость и три подобранных константы).

Контекст правки: сводка ВСЕГО выпуска (батчами; прежний `[:8000]` покрывал 12%), отдельный
recall-шаг «какие сущности здесь упомянуты» (его удаление уронило полноту — `Midjourney`, `CUDA`)
и по **одной целой реплике** соседей с каждой стороны (единица — реплика из диаризации; символы и
токены рвут фразы; две реплики глушат внимание к фрагменту). Реплики правятся параллельно
(507→~100 с на выпуск), срыв одной оставляет её сырой, не роняя выпуск.

## Отвергнутые альтернативы (все — по замерам)

- **Фонетический якорь** (translit+difflib): не разделяет — «его лемку»→`Midjourney` 0.11,
  «Пакков»→«Павлов» 0.67. Работал в старом Классе-1, где кандидаты шли из фонетического шортлиста.
- **Акустический переспрос** каждой замены: подсказка перебивает звук (39% случаев — «эффект
  попугая»), а на упрямом гарбле рубит лучшие починки (19%).
- **Частотность/NER источника**: Whisper ошибается в сторону знакомых слов — «Куда?»→`CUDA`,
  «игрок»→`Grok`; запрет трогать частотное вырезал бы сердце стадии.

## Последствия

- Худший исход правки теперь — «замена не применилась»; удалить или переписать речь физически нечем.
- Вчетверо быстрее свободного переписывания (список короче генерировать) при той же полноте.
- Непобеждённый класс: подмена сущности на сущность **без смены числа** («Пакков»→«Павлов») —
  текстовых признаков нет, обе версии правдоподобны во всём, кроме факта. Страховка — raw-сайдкар;
  кандидат — пометка таких замен для точечного аудита (Слой 2 из доки приключения).
- Отбор замен консервативен: часть жемчужин recall не доходит до текста (`CUDA`, `Kaspersky` в
  отдельных прогонах). Осознанный размен: ложная правка в базе знаний дороже непочиненного гарбла —
  гарбл виден, подмена выглядит как правда.
- Проверка изменений стадии — чтением: karaoke-страницы (`make_karaoke.py`) с подсветкой правленых
  слов; класс «смена числа» нашло именно чтение, метрики его пропустили.
