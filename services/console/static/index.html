Индексация

👋 Добро пожаловать в консоль Morag!
Для запуска индексации откройте раздел Настройка и сконфигурируйте:
  1. Источники — откуда брать документы (локальная папка, Confluence, Jira)
  2. LLM — какие модели использовать (Ollama / Grok / OpenRouter / свой сервер)
  3. Embedder — модель для векторного поиска (Ollama qwen3-embedding или OpenAI)
  4. Роли — какая LLM на текстовые задачи, какая на vision (PDF, изображения)
  5. Расписание (необязательно) — автоматическая переиндексация по cron
→ Перейти к настройке

Карта знаний

⚡ Быстрая настройка для Ollama

Рекомендуется для локального запуска: одна multimodal LLM (qwen3.5:9b, для текста и vision) и dense embedder (qwen3-embedding:4b, dim 2560) через локальный Ollama-сервер.

Следующий шаг: добавьте источник в секции «1. Источники» ниже — например, локальную папку с документами.

1. Источники

Источников ещё нет. Добавьте хотя бы один — например, локальную папку.
⏳

2. LLM

LLM ещё не настроены. Добавьте хотя бы одну текстовую модель (DocSummary, Context и пр.) и одну vision (PDF / изображения). Можно использовать одну multimodal-модель сразу для обеих ролей.
⏳

3. Embedder

Один dense-эмбеддер для индексации и поиска. Стандарт morag — qwen3-embedding:4b (Ollama, 2560 dim). При смене модели — потребуется полная переиндексация.
⏳

4. Роли

Какая LLM из пула используется для каких задач индексации. Список vision-моделей фильтруется по capability.
В пуле нет ни одной vision-модели. Добавьте LLM выше с галкой «Vision-capable».
⏳

5. Расписание

Автоматическая индексация по cron. По умолчанию выключена — включается осознанно. Запись в config.local.yml, применяется без перезапуска контейнера.
Стандартный crontab: минута час день месяц день_недели. Примеры: 0 */6 * * * (каждые 6 часов), 0 3 * * * (ежедневно в 03:00).
